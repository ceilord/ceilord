quality score.

Generation and QA are separate model calls. The checker uses explicit criteria from the job, then Ceilord retries once or stops.

Call 01 / write engine path

The writing call gets the instructions and provided requirements, then produces the piece itself.

No “help me write this” chat loop. The generation call is asked to address every part and match the requested length or format when one is stated.

Why not just use ChatGPT or Claude?

You can. The beta question is narrower: can Ceilord get the same real writing job to an acceptable result with less operator intervention? Bring a brief you already know and compare the workflows.

Is Ceilord a rewriting tool?

No. Give it a topic, brief, instructions, context, or constraints. Ceilord writes the piece itself.

Is the API live?

No. Direct product access is the current beta. API and SDK access are planned.

Does Ceilord keep repairing until it passes?

Not yet. The current engine runs structured QA, retries once after a failed check, then stops if QA still fails.
